# 🐚 Руководство по Интеграции с Оболочками (Zsh & Bash)

**Proxy CLI** предназначен для удобного использования в интерактивных сессиях командных оболочек. Поскольку процессы в Unix не могут напрямую менять переменные окружения родительского шелла, `proxy-cli` использует генератор интерактивных функций.

---

## ⚡ Интеграция с Zsh (Oh My Zsh / Powerlevel10k)

### 1. Подключение
Добавьте следующую строку в ваш файл `~/.zshrc`:

```zsh
eval "$(proxy-cli init zsh)"
```

### 2. Совместимость с Powerlevel10k Instant Prompt
Если вы используете тему **Powerlevel10k** с включенным *instant prompt*, добавление `eval "$(proxy-cli init zsh)"` в `~/.zshrc` происходит абсолютно **бесшумно** без какого-либо консольного I/O вывода. Это предотвращает предупреждения `Console output during zsh initialization detected`.

### 3. Индикатор прокси для строки приглашения (Prompt)
Вы можете вывести статус активного прокси прямо в prompt вашего терминала.
Добавьте вызов `prompt_proxy_status` в вашу функцию генерации prompt или кастомный сегмент Powerlevel10k:

```zsh
# Пример вывода в prompt:
# 🌐 [Throne:2080]
```

## 🐚 Интеграция с Bash

Добавьте следующую строку в файл `~/.bashrc` или `~/.bash_profile`:

```bash
eval "$(proxy-cli init bash)"
```

Затем перезагрузите сессию:
```bash
source ~/.bashrc
```

---

## 🛠️ Сгенерированные функции оболочки

После выполнении `eval "$(proxy-cli init <shell>)"` вам доступны следующие стандартные команды:

| Команда | Описание |
| :--- | :--- |
| `proxy` | Главная обертка над утилитой (`proxy on`, `proxy off`, `proxy status`, `proxy use <key>`) |
| `proxy_on` | Включить прокси в текущей вкладке терминала (`export ALL_PROXY=...`) |
| `proxy_off` | Выключить прокси в текущей вкладке (`unset ALL_PROXY ...`) |
| `proxy_toggle` | Переключить состояние (если включен — выключить, если выключен — включить) |
| `proxy_status` | Вывести текущий IP, статус, IPv4, IPv6 и Локацию |
| `proxy_ping` | Выполнить замер задержек до целевых сервисов |
| `proxy_diagnose` | Выполнить диагностику локального сокета и API |
| `proxy_run <cmd>` | Выполнить разовую команду через прокси |
