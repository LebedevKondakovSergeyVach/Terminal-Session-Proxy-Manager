# 📖 Руководство по Использованию и Справочник Команд

Справочник всех подкоманд и флагов **Proxy CLI** с примерами вывода.

---

## 🟢 1. Статус сети и Геолокация (`status`)

Выводит текущий статус прокси, активный протокол/хост/порт, внешний IPv4, IPv6 и физическую локацию (город, страна, код страны).

```bash
proxy status
# или напрямую через бинарник:
proxy-cli status
```

### Пример текстового вывода:
```text
----------------------------------------------------------
Статус:  🟢 ВКЛЮЧЕН [Throne -> socks5://127.0.0.1:2080]
IPv4:    80.209.240.41
IPv6:    недоступен
Локация: New York, United States (US)
----------------------------------------------------------
```

### Вывод в формате JSON:
Флаг `--json` позволяет выводить статус в структурированном виде для парсинга в скриптах:
```bash
proxy-cli status --json
```
*Пример вывода:*
```json
{
  "status": "🟢 ВКЛЮЧЕН",
  "profile_key": "throne",
  "profile_name": "Throne",
  "active_proxy": "socks5://127.0.0.1:2080",
  "ipv4": "80.209.240.41",
  "ipv6": "недоступен",
  "location": "New York, United States (US)"
}
```

## 🔄 2. Управление профилями (`profile`)

### Список профилей:
```bash
proxy-cli profile list
```
*Пример вывода:*
```text
📋 Список профилей в config.json:
  • throne       — Throne (127.0.0.1:2080) (активный)
  • v2ray        — v2rayN (127.0.0.1:10808)
```

### Переключение профиля:
```bash
proxy-cli profile use v2ray
# или короткая форма через оболочку:
proxy use v2ray
```

### Добавление / Изменение профиля:
```bash
proxy-cli profile set myvps --name "My VPS Server" --port 1080 --host 127.0.0.1 --protocol socks5
```

### Удаление профиля:
```bash
proxy-cli profile remove myvps
```

## ⚡ 3. Замер задержки (Ping) (`ping`)

Выполняет асинхронный неблокирующий замер HTTP/HTTPS задержки до ресурсов, указанных в `ping_targets` файла `config.json`.

```bash
proxy ping
```
*Пример вывода:*
```text
==========================================================
   ⚡  ЗАМЕР ЗАДЕРЖКИ (PING) СЕРВИСОВ ЧЕРЕЗ ПРОКСИ
==========================================================
Активный сокет: socks5://127.0.0.1:2080 (Throne)

  • Google API         — ✅ OK (320 ms) [HTTP 404]
  • GitHub             — ✅ OK (180 ms) [HTTP 200]
  • OpenAI API         — ✅ OK (410 ms) [HTTP 421]
  • Anthropic API      — ✅ OK (390 ms) [HTTP 404]
  • Telegram API       — ❌ Ошибка / Таймаут
==========================================================
```

### Кастомный таймаут (в миллисекундах):
```bash
proxy-cli ping --timeout 2000
```

## 🔍 4. Расширенная диагностика (`diagnose`)

Проверяет состояние локального сокета клиенты прокси и критичные эндпоинты.

```bash
proxy diagnose
```
*Пример вывода:*
```text
==========================================================
      🔍 РАСШИРЕННАЯ ДИАГНОСТИКА СЕТИ И ПРОКСИ
==========================================================
Активный профиль : Throne (throne)
Активный хост/порт: 127.0.0.1:2080

1. Проверка локального сокета (127.0.0.1:2080): ✅ Порт открыт (клиент активен)

2. Переменные окружения текущей сессии:
   • http_proxy  = http://127.0.0.1:2080
   • https_proxy = http://127.0.0.1:2080
   • ALL_PROXY   = socks5://127.0.0.1:2080
   • GRADLE_OPTS = -Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=2080...

3. Доступность критичных эндпоинтов (таймаут 3с):
   • Gemini API (https://generativelanguage.googleapis.com): ✅ Доступен (HTTP 404)
   • Cloud Code (https://daily-cloudcode-pa.googleapis.com): ✅ Доступен (HTTP 404)
==========================================================
```

## ⚡ 5. Выполнение разовых команд (`run`)

Запускает дочернюю команду с внедрением переменных окружения прокси без изменения переменных текущего терминала.

```bash
proxy run -- curl https://api.openai.com
proxy run -- git clone https://github.com/example/repo.git
```

## ⚙️ 6. Управление путями и настройками (`settings` / `config`)

### Показать пути:
```bash
proxy-cli settings path    # Показать путь к settings.json
proxy-cli config path      # Показать путь к активному config.json
```

### Показать настройки:
```bash
proxy-cli settings show    # Показать содержимое settings.json
proxy-cli config show      # Показать содержимое active config.json
```

### Сменить файл конфигурации:
```bash
proxy-cli settings set --config-path "./configs/config.default.json"
```
