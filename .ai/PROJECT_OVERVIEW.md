# Terminal-Session-Proxy-Manager (proxy-cli-rs)
**AI Context & Project Overview**

## О проекте (About the Project)
Универсальный CLI-инструментарий на языке Rust для управления прокси-соединениями (SOCKS5, HTTP) в терминале. 
Позволяет быстро переключаться между профилями прокси, замерять их скорость (бенчмарк), а также экспортировать настройки для Docker, Git, cURL и окружения (env variables).

## Основной стек технологий
- **Язык:** Rust 1.70+
- **CLI Парсер:** `clap` (v4) с сабкомандами.
- **Асинхронность:** `tokio`
- **Сетевые запросы:** `reqwest` (с поддержкой socks5).
- **TUI (Терминальный интерфейс):** `ratatui` + `crossterm` (используется в `src/cmd/dash.rs` для красивого дашборда).
- **Интерактивные меню:** `dialoguer`
- **Сериализация конфигураций:** `serde` + `serde_json`

## Структура кодовой базы
- `src/main.rs`: Точка входа, парсинг аргументов CLI.
- `src/cli.rs`: Описание всех подкоманд CLI с двуязычной документацией (`/// English | Русский`).
- `src/cmd/`: Реализация бизнес-логики каждой команды (например, `dash.rs` для TUI, `import_cmd.rs` для парсинга, `env.rs`, `git.rs` и т.д.).
- `src/config/`: Модели данных.
  - `app.rs`: Работа с `config.json` (прокси профили, эндпоинты для пинга).
  - `settings.rs`: Работа с глобальными настройками `settings.json` (выбор языка).
  - `i18n.rs`: Локализация.
- `locales/`: JSON-файлы с переводами (ru.json, en.json). Ключи должны быть синхронизированы 1 к 1!

## Особенности архитектуры
1. **Динамическая генерация базового конфига:** 
   Если у пользователя нет `config.json`, программа (`src/config/app.rs`) генерирует базовый шаблон с профилями `default` (1080) и `custom` (8080).
2. **Локализация:** 
   Строки внутри кода приложения локализованы через механизм `I18n::t()`. Файлы переводов лежат в `locales/`. Справка командной строки (`--help`) локализована статично внутри `src/cli.rs` с помощью двойных комментариев `/// En | Ru`.
3. **Безопасность конфигураций:**
   Приватные профили (напр., файлы с личными IP и портами) не должны коммититься в репозиторий.
